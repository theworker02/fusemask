# fusemask

Fuse lightweight mask statistics from stdin samples.

**Site:** https://theworker02.github.io/fusemask/

## Install / run

```bash
git clone https://github.com/theworker02/fusemask.git
cd fusemask
node src/cli.js
node --test
```
